# 💰 Personal Expense Analyzer

## 📌 Project Overview

The Personal Expense Analyzer is a beginner-friendly Data Science project developed using Python.

The project analyzes personal spending data and helps users understand where their money is being spent through data analysis and visualizations.

---

## 🎯 Problem Statement

People spend money on food, travel, shopping, bills, and entertainment, but it can be difficult to understand which categories consume the most money.

This project analyzes expense data and identifies important spending patterns.

---

## 💡 Solution

The system analyzes expense records and provides:

- Total spending
- Average transaction amount
- Category-wise spending
- Highest spending category
- Largest individual expense
- Daily spending trends
- Visual representation of expenses

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

---

## 📊 Analysis Performed

The project performs the following steps:

1. Creates and loads expense data
2. Checks the structure of the dataset
3. Checks for missing values
4. Checks for duplicate records
5. Converts dates into the correct format
6. Calculates total and average spending
7. Performs category-wise analysis
8. Identifies the highest spending category
9. Identifies the largest transaction
10. Visualizes spending patterns

---

## 📈 Visualizations

The project includes:

- Bar Chart – Spending by Category
- Pie Chart – Expense Distribution
- Line Chart – Daily Spending Trend

---

## 🔍 Key Insights

- Total spending analyzed: ₹4,289
- Shopping was the highest spending category at ₹1,950
- Average transaction amount was approximately ₹357.42
- Largest individual expense was ₹1,200
- Travel had the lowest total spending at ₹310
